This page describes the website and sandbox demo available today.

Updated October 3, 2026

What you can use without sharing

You can browse this website and try the interactive demo without creating an account or entering an email address. There is no signup, payment, or contact-data collection form in this preview.

The demo is fictional

Names, group details, responses, and offers in the demo are sample data. Actions happen only in your current browser page. This website’s code does not send invitations, email anyone, or create a real group.

Demo state is kept in memory. It resets when you reload the page or use Reset. The demo does not use local storage, session storage, or cookies to save your choices.

Technical data from visiting the site

The hosting provider may process technical request data, such as IP addresses, browser information, requested pages, and request times, to deliver and secure the website. This is separate from the fictional demo data. The provider depends on where you access this preview: Vercel’s privacy policy applies to Vercel-hosted copies, and OpenAI’s privacy policy applies to copies hosted in ChatGPT.

No added marketing trackers

This site’s source does not include analytics scripts, advertising pixels, embedded social widgets, or third-party web fonts. The demo does not make API requests. Hosting infrastructure may still maintain technical logs.

As the product develops

Real accounts and group invitations will require a fuller explanation of data collection, retention, deletion, and service providers. That information will be provided before those features become available. Please do not treat this preview as a place to store real member information.
